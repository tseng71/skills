# Privacy Policy for image-deck

Effective date: August 3, 2026

`image-deck` is a skills-only plugin. It does not operate an external server, create user accounts, or independently collect, transmit, sell, or store personal data.

The workflow runs inside the ChatGPT or Codex host selected by the user and may use host-provided capabilities such as file reading, web research, and image generation when needed for the requested presentation. Data handled by those host capabilities is governed by the applicable OpenAI terms and privacy policies.

Users should not include confidential, personal, or restricted information unless they are authorized to process it in the selected ChatGPT or Codex environment. Source files and generated presentation content remain subject to the user's organization policies and applicable law.

Questions may be submitted through [GitHub Issues](https://github.com/tseng71/skills/issues).
